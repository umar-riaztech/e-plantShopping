# e-plantShopping

## Paradise Nursery - Online Plant Shopping Application

A React-based online plant shopping application where users
can browse plants, add products to their shopping cart,
manage quantities, and calculate their total purchase amount.

## Features

- Browse plants by category.
- View plant images, descriptions, and prices.
- Add plants to the shopping cart.
- Increase and decrease product quantities.
- Remove products from the cart.
- Calculate individual subtotals and total cart amount.
- Redux state management.

## Technologies Used

- React
- JavaScript
- Redux Toolkit
- React Redux
- CSS
- Git and GitHub
